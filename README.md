# Neo Clean

A responsive, frontend-only product catalogue for Neo Clean, a cleaning-products brand in Nashik. It uses plain HTML, CSS, and JavaScript, so it needs no build step or server.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload the **contents of this `neoclean-store` folder** to the repository root and commit them to `main`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

GitHub Pages will serve `index.html` directly. Keep `assets/`, `styles.css`, and `script.js` at the same relative paths. No Node.js, database, secrets, or workflow is required.

## What works

- Responsive product catalogue with category filters and search.
- Demo cart saved in the current browser, with email enquiry via the visitor's email app.
- Clickable phone, email, and map links.

The site does not process payments, submit orders to a server, or store customer data remotely. Product photos are original AI-generated illustrations; packaging and appearance may differ from actual products.
